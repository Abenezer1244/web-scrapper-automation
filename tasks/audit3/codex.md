## Codex scope

Read-only source review of the backend at origin/main and the frontend at `C:/Users/Windows/OneDrive - Seattle Colleges/Desktop/bridgeleads-web`. I traced every FastAPI route carrying a job, scraper, batch, run, result, notification, or connector identifier across its supported HTTP methods, including start, view, cancel, results, export, download, and Live Run SSE paths. I also reviewed RLS context binding, worker ownership joins, plan and quota gates, admin dependencies, Stripe checkout and webhook handling, Tracerfy ingestion and billing, outbound HTTP and Playwright SSRF controls, CSV/XLSX generation, frontend Auth.js/API usage, CSP, CORS, CSRF posture, SQL construction, logging, and production error handling.

No tests, application processes, network requests, or `.env` files were used. No secret values are included.

## Not verified

- No runtime exploit validation, tests, app startup, browser execution, database connection, Celery execution, Stripe call, Tracerfy call, or external network request was performed.
- The reviewed HTTP ID-bearing routes use caller ownership predicates or owner-joined queries for job start, view, cancel, results, SSE logs, export, download, scraper configs, batches, batch runs, notifications, and cached records. I found no confirmed direct HTTP IDOR or BOLA in those paths.
- Admin authorization is server-side through `require_admin` and `require_admin_mfa`; frontend admin navigation is treated as presentation only.
- Stripe signature verification, durable event-ledger deduplication, subscription re-reads, plan-price allowlists, payment-method collection, and duplicate-subscription checks were traced in code. Promo and zero-dollar checkout behavior was not exercised against Stripe.
- CSV and XLSX exports use the canonical sanitized lead builder, and no active dynamic ORDER BY or NoSQL query construction was found in the reviewed source. Export behavior was not opened in a spreadsheet application.
- CORS is allowlisted rather than wildcarded, API authentication uses bearer headers rather than ambient cookies, and no obvious frontend DOM XSS sink beyond a generated chart style block was found. Deployment proxy behavior, browser extensions, third-party scripts, and production headers were not independently verified.
